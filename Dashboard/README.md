# Interactive Dashboard

This directory documents the interactive dashboard developed for the NERC Electricity Analytics project.

## Visualization Platform
Google Looker Studio

## Dashboard Objectives
- Examine electricity industry performance.
- Compare electricity distribution companies.
- Explore revenue, billing, and metering indicators.
- Analyze customer complaints and service performance.
- Communicate findings through interactive visualizations.
