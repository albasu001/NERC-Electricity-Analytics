# Data Dictionary — NERC Q1 2025

## 1. Dataset Overview

This workbook contains extracted tables from the Nigerian Electricity Regulatory Commission (NERC) Q1 2025 quarterly report.

- Reporting period: First Quarter 2025
- File format: Excel (.xlsx)
- Number of worksheets: 190
- Original source format: PDF

## 2. Worksheet Organization

The workbook contains individual worksheets named using the following convention:

`Table_[Table Number]_p[PDF Page Number]`

Examples:
- `Table_17_p18`
- `Table_24_p23`
- `Table_43_p36`

The naming convention helps trace extracted tables back to their corresponding source report pages.

## 3. Data Categories

The extracted report tables cover different aspects of the Nigerian electricity supply industry.

These include, where represented in the source tables:

- Electricity generation and available capacity
- Transmission and distribution performance
- Distribution company operations
- Energy offtake and billing
- Metering performance
- Revenue and remittance
- Customer complaints and service performance

## 4. Units of Measurement

Units are retained according to the original report tables. Examples include:

- MW — Megawatts
- MWh — Megawatt-hours
- GWh — Gigawatt-hours
- MWh/h — Average hourly generation
- Percentage (%) — Performance ratios and rates
- Nigerian Naira (₦) — Financial values

## 5. Data Interpretation

Individual worksheets may have different table structures, headers, reporting periods, and measurement units.

Users should consult the original NERC report when interpreting extracted values.

## 6. Data Limitations

The extracted workbook is an intermediate dataset. Table formatting, merged cells, transcription accuracy, missing values, and consistency should be assessed before analytical use.
