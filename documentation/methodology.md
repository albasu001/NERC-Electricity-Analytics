# Project Methodology

## 1. Data Source
The primary data sources for this project are quarterly electricity industry reports published by the Nigerian Electricity Regulatory Commission (NERC).

The reports are originally published in PDF format.

## 2. Data Extraction
Relevant tables and information were extracted from the original PDF reports through a transcription and table extraction process.

The extracted information was organized into structured Excel worksheets to facilitate further processing and analysis.

## 3. Data Organization
The extracted tables were compiled into an Excel workbook.

The workbook serves as the intermediate dataset between the original PDF reports and subsequent analytical processes.

## 4. Data Processing
Python scripts are used to support data processing, cleaning, transformation, and preparation for analysis.

## 5. Data Analysis
The prepared datasets will support the examination of electricity industry performance indicators, including comparisons across distribution companies and reporting periods where the available data permits.

## 6. Data Visualization
Google Looker Studio will be used to develop interactive dashboards that communicate key performance indicators, comparisons, and analytical findings.

## 7. Project Outputs
- Original NERC PDF reports or their official source references.
- Extracted Excel workbooks.
- Python scripts.
- Cleaned and processed datasets.
- Interactive Looker Studio dashboard.
- Analytical findings and visualizations.

## 8. Project Status
Data extraction and initial organization have been completed. Data processing, analysis, and dashboard development are subsequent project stages.
