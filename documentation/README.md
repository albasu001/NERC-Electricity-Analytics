# Project Documentation

This directory contains documentation supporting the NERC Electricity Analytics project.

## Documentation Files

- methodology.md: Data extraction and processing methodology.
- data_dictionary.md: Description of dataset fields and variables.
- data_quality.md: Data validation and quality assessment.
- findings.md: Key findings and analytical insights.

## Project Scope

The project uses NERC quarterly electricity industry reports as source materials for data extraction, preparation, analysis, and visualization.
